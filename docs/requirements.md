## 2. 业务需求（BR）

| 编号 | 需求 | 描述 | 优先级 | 来源 | 验证方式 |
|---|---|---|---|---|---|
| BR-01 | 多类型文档入库 | 支持 docx/pdf/md/html/表格 ≥5 种格式，抽取正文与元数据 | P0 | 各事业部 | 入库成功率 ≥99%（对应 S1） |
| BR-02 | 向量检索问答 | 自然语言提问，返回**带引用来源**的回答 | P0 | 全角色 | 引用可追溯率 100%（S2） |
| BR-03 | 版本管理 | 文档版本编号、变更记录、历史回溯 | P0 | 痛点 P2 | 历史版本可回溯（S4） |
| BR-04 | 生命周期治理 | 入库/更新/过期淘汰/下线闭环 | P0 | 痛点 P1 | SOP 覆盖 4 主线（S5） |
| BR-05 | 错误反馈闭环 | 用户反馈错误→复核→修订→回写 | P0 | 痛点 P3 | 闭环率 ≥95%（S7） |
| BR-06 | 角色场景覆盖 | 8 类角色的查询/诉求/权限/风险均有落点 | P1 | 干系人 | 场景清单逐项验收 |

## 3. 算法需求（AR）

> 强调：本项目展示**治理与项目管理**，算法需求仅到「需求规格」层级，不做调优承诺。

| 编号 | 需求 | 描述 | 优先级 | 验证方式 |
|---|---|---|---|---|
| AR-01 | 文档切块与向量化 | 按语义边界切块，生成向量索引 | P0 | 切块粒度可配置 |
| AR-02 | 检索排序与召回 | 向量相似度 + 关键词混合检索，返回 Top-K | P0 | 召回率达标（见评估） |
| AR-03 | 引用溯源生成 | 回答显式引用来源文档与片段 | P0 | 每条回答含来源锚点 |
| AR-04 | 幻觉抑制 | 无知识覆盖时**拒答**而非编造 | P0 | 幻觉率达标（见评估） |

## 4. 安全合规需求（SR）

| 编号 | 需求 | 描述 | 优先级 | 验证方式 |
|---|---|---|---|---|
| SR-01 | 事业部权限隔离 | 检索范围按事业部隔离，跨域访问阻断 | P0 | 越权访问率 = 0（S3） |
| SR-02 | 密级双层管控 | 事业部 + 密级双维度，高层级不可向低层级透传 | P0 | 密级越权回归 |
| SR-03 | 数据分级与脱敏 | 按分级规则对敏感字段脱敏 | P0 | 脱敏规则命中审计 |
| SR-04 | 审计留痕 | 检索/回答/权限变更全链路留痕 | P0 | 审计日志可查证 |

> **行业专项合规**（出口管制、数据不出域、跨境约束等）见 `industry-appendix.md`，作为可插拔增强，不改变本节通用基线。

## 5. 非功能需求（NR）

| 编号 | 需求 | 描述 | 优先级 | 验证方式 |
|---|---|---|---|---|
| NR-01 | 性能与容量 | 1000+ 人并发查询，检索 P95 < 2s | P0 | 压测报告 |
| NR-02 | 可用性与容灾 | 服务可用性 ≥ 99.5%，故障可恢复 | P1 | 可用性监控 |
| NR-03 | 可维护可运营 | 治理组织 + SOP + 台账可持续运转 | P0 | 运营台账持续更新 |
| NR-04 | 行业可插拔 | 半导体/新能源差异不侵入主干，可开关启用 | P1 | 附录独立、主干无行业字段 |

## 6. 需求—风险追溯矩阵（节选）

| 需求 | 关联风险 | 说明 |
|---|---|---|
| BR-01 / BR-04 | R01（归集阻力）、R06（质量参差） | 入库与治理直接对抗归集与质量风险 |
| BR-02 / AR-04 | R03（幻觉） | 引用溯源 + 拒答抑制幻觉 |
| BR-03 | R02（版本冲突） | 版本管理直面冲突 |
| SR-01~SR-04 | R04（泄露）、R05（越权） | 权限与脱敏缓解泄露/越权 |
| S6（评估） | R07（效果无法量化） | 评估体系解决量化缺失 |

> 风险编号定义见 `risk-log.md`。

## 7. 需求基线管理

- 需求一经评审进入**基线**，变更走 `scope-statement.md` 第 5 节变更流程。
- 每条需求绑定**可验证方式**，杜绝「不可测需求」进入一期。
- 需求优先级以 P0/P1 两档管理，P2 及以下进入 backlog。
